# claude

This directory is reserved for future Claude-specific configuration, prompts, evaluation assets, or workflow notes.

It is intentionally minimal right now because the repository currently preserves only the Codex side of the workbench in a durable, publishable form.

If Claude-specific material is added later, keep the same standard used for the Codex subtree:

- preserve human-managed configuration and durable evaluation assets
- exclude auth state, caches, logs, temporary files, and virtual environments
- document the structure clearly before adding large mirrors of local state
