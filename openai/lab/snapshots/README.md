# snapshots

Keep preserved evidence here:

- prompts
- final responses
- exported transcripts
- reference outputs tied to important evaluations

Use `snapshots/` when you need evidence of what was asked, what Codex returned, or what validation evidence was shown for an important run.

Good fits:

- prompt text for a representative task
- final response text for a meaningful run
- transcript excerpts or exported transcripts worth preserving
- copied validation snippets when they matter for later review

Do not use `snapshots/` as a dump for whole repos or bulk machine outputs that belong in `results/`.
