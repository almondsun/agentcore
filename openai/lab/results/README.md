# results

Keep preserved outputs here:

- run summaries
- comparison JSON or Markdown
- scorecards
- result artifacts worth referencing later

Use `results/` for outputs, not for active task repos.

What belongs here:

- scorecards and summaries
- exported JSON, Markdown, or similar comparison artifacts
- preserved harness or run bundles that you expect to reference later

What does not belong here:

- the source repo for a live task
- scratch logs that are only useful during one disposable session
- prompts or final responses when `snapshots/` is the better fit
